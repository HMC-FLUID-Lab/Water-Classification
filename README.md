# Water ML-Clustering Pipeline

End-to-end pipeline for identifying **Locally Favored Tetrahedral Structures
(LFTS)** and **Disordered Normal-Liquid Structures (DNLS)** in water MD
simulations, following the Shi & Tanaka two-state framework
(*JACS* **142**, 2868 — 2020).

Molecules are described by four local order parameters (ζ, *q*, LSI, *S*ₖ) and
sorted into the two states by an unsupervised **likelihood-ratio (LR)
classifier**: DBSCAN core detection → two-component Gaussian mixture → a
symmetric likelihood-ratio reject band. Molecules that fall in the ambiguous
band between the states are labelled **transition**. This is the method used in
the current manuscript (`6_paper_writing/`, Draft 6).

The custom Structure-Factor Validation Score is documented in
[`3_clustering/SFVS_metric.md`](3_clustering/SFVS_metric.md) and is retained
only as a reference for the earlier validation approach.

---

## The two-state classifier (paper method)

Per molecule, on the four scaled features **[ζ, q, LSI, Sₖ]** (Q6 deliberately
excluded):

1. **Cores** — DBSCAN (`eps = 0.06`, `min_samples = 20`) isolates the dense
   cores and drops sparse noise.
2. **Mixture** — a 2-component full-covariance Gaussian mixture is fit to the
   cores, giving per-state densities *p*₍LFTS₎ and *p*₍DNLS₎.
3. **Likelihood ratio** — Λ(x) = log *p*₍LFTS₎(x) − log *p*₍DNLS₎(x).
   Assign **LFTS** if Λ ≥ +τ, **DNLS** if Λ ≤ −τ, else **transition**
   (ambiguous), with **τ = 2.0**.

For the generality figure the classifier is **fit once** on tip4p2005 at −20 °C
and then **frozen** (stored scaler + GMM + τ) and applied unchanged to every
other temperature and water model, so each panel isolates a single variable.
The reference implementation is
[`5_paper_figures/run_generality_lr.py`](5_paper_figures/run_generality_lr.py)
(`fit_frozen_lr`).

## Pipeline (run in order)

```
  1_simulate           MD trajectories                        → data/simulations/*
  2_order_params       DCD → q, Q6, LSI, Sk, ζ                → data/order_params/*.mat
  3_clustering         MAT → cluster cores + two-state labels → results/clustering/<run>/
  4_structure_factor   labels + DCD → per-cluster S(k)        → results/clustering/<run>/
  5_paper_figures      LR relabelling + manuscript figures    → 6_paper_writing/.../images/
```

The numbered prefix is the running order: stage *N* consumes the output of
stage *N − 1*. Each directory has its own `README.md` documenting the stage.

**Code, order-parameter definitions, and the manuscript source are committed;
raw trajectories, `.mat` order params, and result figures are not** — they are
regenerated by the pipeline (see [.gitignore](.gitignore)).

## Quickstart

Single condition, all five stages (base DBSCAN→GMM clustering + S(k)):

```bash
bash pipeline/run_pipeline.sh tip4p2005 T-20 Run01
```

Skip the (expensive) MD step and start from existing DCDs:

```bash
bash pipeline/run_pipeline.sh tip4p2005 T-20 Run01 --skip 2
```

Reproduce the manuscript (Draft 6) figures from existing order params — see
[Reproduce the paper figures](#reproduce-the-paper-figures) below:

```bash
cd 5_paper_figures
python run_generality_lr.py all      # LR labels + S(k)/generality caches
python make_needed_photos.py         # main-text figures
python make_ver2_skzeta3d.py && python make_ver2_skzeta2d.py   # S(k,ζ) panels
python make_si_figures.py            # SI figures
```

## Stage cheat sheet

### Stage 1 — Simulate

```bash
python 1_simulate/runWater_tip4p2005.py
python 1_simulate/runWater_tip5p.py
# Drude-polarizable SWM4-NDP needs swm4ndp.xml in the run dir:
mkdir -p data/simulations/swm4ndp && cd data/simulations/swm4ndp
python ../../../1_simulate/runWater_swm4ndp_multitemp.py
```

### Stage 2 — Order parameters

```bash
# One condition
python 2_order_params/run_single_condition.py tip4p2005 T-20 Run01

# Every DCD for a model
python 2_order_params/compute_order_params.py --model tip4p2005
```

### Stage 3/4 — Base clustering and per-cluster structure factor

Produces the DBSCAN→GMM label matrix and per-cluster S(k) that the SI figures
and the LR relabelling build on:

```bash
python pipeline/auto_cluster_pipeline.py \
    --mat-file  data/order_params/OrderParam_tip4p2005_T-20_Run01.mat \
    --zeta-file data/order_params/OrderParamZeta_tip4p2005_T-20_Run01.mat \
    --dcd-file  data/simulations/tip4p2005/dcd_tip4p2005_T-20_N1024_Run01_0.dcd \
    --pdb-file  data/simulations/tip4p2005/inistate_tip4p2005_T-20_N1024_Run01.pdb \
    --method dbscan_gmm --eps 0.06 --min-samples 20 \
    --output-dir results/clustering/tip4p2005_T-20_dbscan_gmm
```

Add `--skip-structure-factor` for labels only.
`3_clustering/water_clustering.py` remains the standalone entry point when only
label generation and diagnostic clustering plots are needed.

### Stage 5 — Paper figures

`5_paper_figures/` holds the shared infrastructure plus the LR figure builders:

| file | what it does |
|------|--------------|
| `nature_style.py` | Nature-Physics matplotlib style + colour system. Imported everywhere. |
| `figlib.py` | Shared data loaders + reusable panel builders. |
| `build_data.py` | Builds base caches from the trajectories + `.mat` order params. Run once. |
| `run_generality_lr.py` | **Fits the frozen LR classifier** and writes LR labels + S(k)/generality caches for every condition. |
| `make_needed_photos.py` | Renders the main-text figures (clustering, validation line, generality) from the LR caches. |
| `make_ver2_skzeta3d.py` / `make_ver2_skzeta2d.py` | LR S(k, ζ) 3-D surfaces + 2-D heatmaps (Fig. 2 panels). |
| `make_ver2_figures.py` | LR per-cluster S(k) with the FSDP pre-peak comparison. |
| `make_si_figures.py` | SI figures: cluster-number selection, DBSCAN/HDBSCAN heatmaps, method comparison, per-method order params. |

The superseded confidence-method main renderer (`make_main_figures.py`) has
been moved to `5_paper_figures/_archive/` (gitignored) for reference.

## Reproduce the paper figures

From existing order-parameter `.mat` files (stages 1–2), run everything from
`5_paper_figures/` — the scripts resolve paths from the repo root:

```bash
cd 5_paper_figures

# 0. base caches (needs trajectories + order-param .mat files)
python build_data.py

# 1. fit the frozen LR classifier and write labels + S(k)/generality caches
python run_generality_lr.py all
#    → results/clustering/tip4p2005_T-20_lr/cluster_labels.csv
#    → sk_cache/sk_*_lr.npz, redesign_cache/validation_line_3state_lr.npz
#    → results/clustering/multirun_lr/fractions_blocktrim_lr.csv

# 2. main-text figures
python make_needed_photos.py         # clustering + validation-line + generality
python make_ver2_skzeta3d.py         # S(k,ζ) 3-D surfaces  (Fig. 2)
python make_ver2_skzeta2d.py         # S(k,ζ) 2-D heatmaps  (Fig. 2)
python make_ver2_figures.py          # per-cluster S(k) FSDP comparison

# 3. SI figures
python make_si_figures.py            # add --recompute to rebuild the DBSCAN/HDBSCAN grids
```

The rendered PNGs land under `5_paper_figures/` (gitignored scratch) and the
final selected/cropped figures are collected in
`6_paper_writing/Paper_WaterMLClustering/images/{main,SI}/`. A few composites
(e.g. the Fig. 2 stack) are assembled by hand from the S(k) row and the S(k, ζ)
panels; the committed manuscript bundle carries the final versions.

## The manuscript

The paper lives in `6_paper_writing/Paper_WaterMLClustering/`:

- `Draft6.tex` — current draft (LR method), `\bibliography{bib}` + `achemso`.
- `SI.tex` / `cleaned_SI.tex` — supporting information.
- `images/{main,SI}/` — final figures referenced by the drafts.
- `prev_draft/` — Draft 1–5 history.

Build locally (LaTeX build artifacts are gitignored):

```bash
cd 6_paper_writing/Paper_WaterMLClustering
latexmk -pdf Draft6.tex          # or: pdflatex → bibtex → pdflatex ×2
```

**`Paper_WaterMLClustering.zip`** is the self-contained bundle (all `.tex` +
`images/` + previous drafts) and is the artifact meant for sharing/download. To
copy it to your local machine, from **your local terminal** run:

```bash
scp <user>@<host>:/home/water/WaterSimulation/WaterClassification/6_paper_writing/Paper_WaterMLClustering.zip .
```
